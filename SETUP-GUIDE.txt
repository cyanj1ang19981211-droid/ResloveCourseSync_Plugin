========================================================
  课程强度同步插件 · 安装与环境说明
========================================================

你看到这个文件，说明插件在这台电脑上没找到 Python，
所以暂时跑不起来。下面是解决办法，按顺序看就行。



--------------------------------------------------------
一、这台电脑到底缺什么？
--------------------------------------------------------

这个插件不是「绿色软件」，它需要电脑上装有 Python 才能运行。
需要的是 Python 3.10 或 3.11 —— 达芬奇（DaVinci Resolve）
的脚本接口只认这两个版本，装更高的版本（3.12 / 3.13 / 3.14）
反而连不上达芬奇。

如果电脑上已经有别的版本 Python，那也没关系，
再装一个 3.11 可以和它共存，互不影响。

除了 Python，这台电脑还需要：
  · 达芬奇 DaVinci Resolve，而且必须是「Studio」付费版
    ⚠️ 达芬奇 19.1 之后，「外部进程」调用脚本是 Studio 专属能力：
       免费版只能在达芬奇内部的「工作区 → 脚本」菜单里跑脚本，
       插件这种外部程序一律连不上，改任何设置都没用。
       确认方法：打开达芬奇 →「帮助」→「关于」，或看窗口标题栏，
       写着 Studio 才是付费版。免费版请升级到 Studio。
  · Microsoft Edge（用来显示那个悬浮小窗；Win10/11 一般自带）



--------------------------------------------------------
二、怎么装 Python（有管理员权限时，推荐）
--------------------------------------------------------

1. 打开网址：https://www.python.org/downloads/
   （打不开就用公司能上网的电脑下好安装包，拷过来）

2. 找到 Python 3.11.x 那一栏，下载「Windows installer (64-bit)」，
   文件名类似 python-3.11.x-amd64.exe

3. 双击安装包。**这一步最关键**：
   在第一个界面最下面，有一个复选框

        [ ] Add python.exe to PATH

   **一定要把它勾上！**
   很多「装了却还是找不到 Python」都是因为漏了这一步。

   然后点 Install Now，等它装完。

4. 装完后，回到插件文件夹，双击「检查环境.bat」。
   如果看到一堆 [通过]，就说明好了，可以双击 start.bat 用了。



--------------------------------------------------------
三、没有管理员权限、装不了 Python 怎么办
--------------------------------------------------------

这种情况用「便携版 Python」，不需要安装：

1. 找一台已经能正常用这个插件的电脑
   （或者任何装好了 Python 3.11 的电脑）。

2. 在插件文件夹里新建一个文件夹，路径必须是：

        runtime\python\

   也就是：插件文件夹 -> runtime 文件夹 -> python 文件夹

3. 把那台电脑上的 Python 3.11 整个文件夹的内容，
   全部复制进上面这个 runtime\python\ 里。
   复制完应该长这样：

        runtime\python\python.exe
        runtime\python\pythonw.exe
        runtime\python\Lib\ ...
        runtime\python\DLLs\ ...

4. 复制完，双击「检查环境.bat」，
   报告里会显示「便携版 Python：已发现」。
   有它之后，插件会优先用这个自带的 Python，
   这台电脑上装不装 Python 都无所谓了。

   小提示：整个项目文件夹（含 runtime）可以打包拷给同事，
         对方解压就能用，不用再装任何东西。



--------------------------------------------------------
四、装好 Python 之后还要做什么
--------------------------------------------------------

1. 打开达芬奇，进「偏好设置」->「系统」->「常规」，
   把「External scripting using」设为 Local（本地）。

   不设这一步，插件连不上达芬奇，悬浮窗会一直显示等待。

2. 双击 start.bat。悬浮窗会出现在屏幕上。

3. 双击 convert.bat 导入课件表格（.xlsx），
   可以按住 Ctrl 一次选多个，转完插件会自动读取。



--------------------------------------------------------
五、常见问题
--------------------------------------------------------

问：双击 start.bat 之后什么都没有发生。
答：正常情况下就是这样 —— 插件是后台静默运行的，
    过一两秒悬浮窗会自己弹出来。
    如果等了很久都没有窗口，说明有问题，这时应该会弹出一个
    提示框告诉你原因。如果连提示框都没有，
    就双击「检查环境.bat」，把屏幕上的内容截图发给开发者。

问：双击 bat 文件时，窗口里滚出一堆
    「××× 不是内部或外部命令」。
答：这是旧版本插件的老毛病（bat 文件的编码和系统不匹配），
    新版已经修好了。请确认你用的是最新版：
    去 GitHub 仓库页面重新点 Code -> Download ZIP 下载一次。

问：悬浮窗显示「等待达芬奇…」很久不动。
答：两个可能：
      1) 达芬奇没开，或者没打开时间线；
      2) 达芬奇里没开外部脚本（见上面第四节第 1 条）。
    另外，插件靠「时间线名称」找对应的课程数据，
    时间线名字要和课件名对得上（例如「爬楼机-20min舒缓解压轻氧攀登」）。

问：导入了课件但悬浮窗还是说没数据。
答：课件要先用 convert.bat 转成 JSON 才会被识别。
    转完之后不用重启插件，它每几秒会自己重新读一次。



--------------------------------------------------------
六、给开发者的信息
--------------------------------------------------------

插件文件夹里的「检查环境.bat」会打印完整的中文体检报告，
并把它保存到 .runtime\环境体检报告.txt。
排查问题时直接把这个文件要过来即可。
